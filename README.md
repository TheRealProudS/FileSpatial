# FileSpatial

> **Infinite Local Workspace & Document Canvas**  
> Ein Produkt von Zenkner-Technology.

FileSpatial ist eine moderne visuelle Arbeitsumgebung zur Organisation von Gedanken, Dokumenten, Bildern und Projekten auf einer unendlichen, performanten Arbeitsfläche. Entwickelt für maximale Produktivität, strukturierte Workflows und absolute Datensouveränität.

---

## Kernfunktionen

- **Unendliche 2D-Arbeitsfläche**
  Freies Verschieben, Zoomen und Navigieren ohne räumliche Beschränkungen. Mit stufenlosem Zoom (20% bis 300%) und anpassbarem Punktraster für saubere Ausrichtungen.

- **Vollständige Drag-and-Drop Integration**
  Ziehe Dokumente, Notizen, PDF-Dateien und Bildformate direkt aus deinem Dateimanager auf das Board. Alle Elemente werden sofort als interaktive Karten visualisiert.

- **Multi-Level Projektboards**
  Strukturiere komplexe Vorhaben hierarchisch. Erstelle Projektkarten, die als eigenständige Unter-Whiteboards dienen, und navigiere nahtlos über die integrierte Breadcrumb-Leiste.

- **Integrierter Dokumentenbetrachter**
  Betrachte mehrseitige PDF-Dokumente direkt auf der Arbeitsfläche oder öffne den optimierten Lese-Modus mit Seitensteuerung und Zoom.

- **Live-Volltextsuche**
  Finde Karten, Notizen und abgelegte Dateien in Echtzeit über die Schnellsuche. Per Tastendruck springt die Kamera automatisch zum nächsten Treffer.

- **Visuelle Verbindungslinien**
  Verknüpfe Karten und Dokumente miteinander, um Abhängigkeiten, Wissensgraphen oder Workflows verständlich darzustellen.

- **Farbcodierung & Struktur**
  Weise Karten unterschiedliche Akzentfarben zu, passe Größen stufenlos an oder dupliziere bestehende Elemente mit einem einzigen Klick.

- **Professionelle Farbthemen**
  Wähle zwischen fünf abgestimmten Themes für jede Arbeitsumgebung:
  - *Obsidian* (Fokussierter Dark Mode)
  - *Midnight OLED* (Tiefschwarz für maximale Kontraste)
  - *Cyber Neon* (Dynamische Akzente)
  - *Titanium Light* (Klarer, neutraler Arbeitsbereich)
  - *Warm Paper* (Augenschonendes Lese- und Schreibambiente)

---

## Datenschutz & Architektur

- **100% Local-First**
  Deine Daten gehören dir. Sämtliche Notizen, Dateien und Layouts verbleiben vollständig auf deinem Gerät im Browser-Speicher.
- **Keine Cloud-Abhängigkeit**
  Es werden keine Dokumenteninhalte an externe Server übertragen oder auf fremden Systemen zwischengespeichert.
- **Volle Portabilität (Import & Export)**
  Sichere deine Workspaces jederzeit als .fspatial-Datei oder übertrage sie verlustfrei zwischen verschiedenen Geräten.

## Steuerung & Navigation

| Aktion | Steuerung |
| :--- | :--- |
| **Arbeitsfläche bewegen (Pan)** | Linke Maustaste auf den Hintergrund gedrückt halten und ziehen |
| **Zoom vergrößern / verkleinern** | Mausrad vor / zurück |
| **Element bewegen** | Auf die Kopfzeile der Karte klicken und ziehen |
| **Elementgröße anpassen** | Anfasspunkt an der unteren rechten Ecke ziehen |
| **Unter-Board öffnen** | Doppelklick auf die Projektkarte oder Klick auf Whiteboard öffnen |
| **PDF-Reader öffnen** | Klick auf die Vorschau der PDF-Karte |
| **Schnellsuche** | Suchfeld in der Kopfzeile fokussieren, Eingabe tätigen, mit Enter durch Treffer springen |
| **Raster ausrichten** | Schaltfläche Raster in der Navigationsleiste aktivieren/deaktivieren |
| **Ansicht zentrieren** | Schaltfläche Zentrieren in der Navigationsleiste anklicken |

---

## Erste Schritte

1. **Notiz anlegen**: Klicke in der Menüleiste auf Notiz, um eine neue Textkarte auf der Arbeitsfläche zu platzieren.
2. **Dateien hinzufügen**: Ziehe beliebige Bild- oder PDF-Dateien direkt per Drag-and-Drop auf die Arbeitsfläche oder nutze die Schaltfläche Datei.
3. **Unter-Whiteboards erstellen**: Erstelle über Projekt eine neue Ebene für strukturierte Teilbereiche.
4. **Workspace sichern**: Nutze die Export-Schaltfläche, um deinen Arbeitsstand lokal zu archivieren.
